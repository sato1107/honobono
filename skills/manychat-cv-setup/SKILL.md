# CVリールの自動返信設定（ManyChat ＋ Lメッセージ）

## 入力

2つの番号を使う。

- **コピー元番号**（例：42）…複製のもとにする前回のCV番号
- **設定先番号**（例：43）…今回新しく作るCV番号

「メニーチャットの設定をして」と言われたら、ブラウザ操作を始める前に、まず次のように質問する。

> コピー元と設定先のCV番号を教えてください。
> 例：「42 43」（CV42をコピーしてCV43を設定）

返答の読み取り方は次のとおり。

- 「42 43」「42→43」「42、43」のように2つの数字があれば、1つ目をコピー元、2つ目を設定先とする。
- 数字が1つだけの場合は、それを設定先とし、コピー元を「設定先−1」と仮定して確認する。
- 依頼文の時点で番号が2つとも書かれていれば、質問は省略してよい。
- 数字が読み取れない場合は、もう一度質問する。

以下の手順では、コピー元番号を `{元}`、設定先番号を `{先}` と書く。実際の操作では必ず数字に置き換え、波かっこは入力しない。

## 開始前の確認

作業を始める前に、次の内容をユーザーに示して了承を得る。

> コピー元：CV{元}／リール{元}
> 設定先：CV{先}／リール{先}
> この内容で進めてよいですか？

次の場合は作業を止めてユーザーに報告する。

- ManyChatまたはLメッセージにログインしていない
- 「CV{先}」または「リール{先}【オートウェビナー】_新規友だち」がすでに存在する（二重作成を防ぐ）

## 手順

各工程が終わるごとに、結果を短く報告する。

### 1. ManyChat：自動化を複製する

app.manychat.com の「オートメーション」→「私の自動化」の一覧を開く。

1. 「CV{元}」の行の「⋮」→「重複」を押して複製する。
2. 複製した自動化（「CV{元} copy」など）の名前を「CV{先}」に変える。
3. トリガー（When…）を開いて、次のように設定する。
   - ステップ1/3：「次の投稿またはリール」を選ぶ
   - ステップ2/3：「何かコメントはありますか？」を選ぶ
   - ステップ3/3：公開返信の設定は変更しない
4. 保存してトリガーをオンにする。「トリガーが保存され、オンになりました」の表示を確認する。

### 2. Lメッセージ：流入経路（QRコードアクション）を作る

step.lme.jp の「QRコードアクション」を開く。

1. 「リール{元}【オートウェビナー】_新規友だち」をコピーする。
2. コピーしたものを開き、次のように設定する。
   - 管理名：「リール{先}【オートウェビナー】_新規友だち」
   - フォルダ：「IG」
3. 「アクション追加・編集」を開き、タグのアクションを次のように変更する。
   - 「タグ新規追加」で「リール{先}【オートウェビナー】」を作る
   - 選択済みのタグから「リール{元}【オートウェビナー】」を外し、「リール{先}【オートウェビナー】」を選ぶ
4. ステップ配信（【リール】オートウェビナー申込の流れ）とリッチメニュー（表示を停止）のアクションは変更しない。
5. 「保存」を押す。
6. 一覧に戻り、「リール{先}【オートウェビナー】_新規友だち」の「QRコード表示」を押して、アクションURL（https://s.lmes.jp/landing-qr/ で始まるURL）をコピーする。

### 3. ManyChat：ボタンのリンクを差し替える

1. 「CV{先}」の編集画面を開き、「編集自動化」を押す。
2. 「Send Message #1」の「今すぐLINEで視聴する👀」ボタンを開く。
3. 「ウェブサイトのURL」を、2でコピーしたURLに丸ごと置き換えて「終わり」を押す。
4. 右上の「アップデート」を押して反映する。

## やってはいけないこと

- コピー元（CV{元}、リール{元}）の設定を変更・削除しない。
- メッセージの文面・画像・公開返信の文面は変更しない。
- 手順にない設定を推測で変更しない。画面が想定と違う場合は、そこで止めてユーザーに報告する。

## 最終報告

最後に、次の3つを報告する。

1. CV{先}のトリガーが「次の投稿またはリール」でオンになっているか
2. 「今すぐLINEで視聴する👀」ボタンに設定したURL
3. Lメッセージで設定したタグ名

報告の最後に、次の注意を添える。

> トリガーが「次の投稿またはリール」のため、CV{先}を投稿する前に設定がオンになっている必要があります。前回のCV{元}をまだ投稿していない場合、両方が同じ投稿に反応する可能性があります。ボタンのURLとトリガーのオンは、ご自身でも確認してください。
