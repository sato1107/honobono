# CV投稿日のLINE通知

かめさん・ころさんの「IGスケジュール管理」の「腸活ダイエット」シートで、企画列（E列）に `CV` を含む行があり、その投稿日付（C列）が今日のとき、毎朝8時台にLINEへ通知します。

```
本日はCVの投稿予定日です かめさん_CV21
本日はCVの投稿予定日です ころさん_CV9
```

- 企画名が「CVリール21」の場合も `CV21` と表示します。
- 同じ日に複数あれば、1通にまとめて送ります。

## 前提：LINE Notify は使えません

LINE Notify は2025年3月31日にサービスを終了しています。そのため、LINE公式アカウントの **Messaging API**（プッシュメッセージ）で送ります。無料のコミュニケーションプランの月間送信上限内（1日最大1通なので月30通程度）に収まります。

## 設定手順

### 1. LINE側（チャネルアクセストークンと送信先ID）

1. [LINE Developers コンソール](https://developers.line.biz/console/) で、プロバイダーと **Messaging API チャネル** を作成する（LINE公式アカウントが作られます）。
2. チャネルの「Messaging API設定」タブで **チャネルアクセストークン（長期）** を発行してコピーする。
3. 通知を受けたいLINEアカウントで、その公式アカウントを友だち追加する。
4. 送信先IDを用意する。
   - 自分1人に送る場合：「チャネル基本設定」タブの **あなたのユーザーID**（`U` で始まる）。
   - グループに送る場合：公式アカウントをグループに招待し、グループID（`C` で始まる）を取得する。グループIDはWebhookのイベントからしか取れないため、自分宛てのほうが簡単です。

### 2. Google Apps Script側

1. [script.google.com](https://script.google.com/) で「新しいプロジェクト」を作成する（スプレッドシートのアカウントと同じGoogleアカウントで）。
2. `Code.gs` の中身をすべて貼り付ける。
3. 左の歯車「プロジェクトの設定」で：
   - タイムゾーンを「(GMT+09:00) 東京」にする。
   - 「スクリプト プロパティ」に次の2つを追加する。

     | プロパティ | 値 |
     | --- | --- |
     | `LINE_CHANNEL_ACCESS_TOKEN` | 手順1-2のトークン |
     | `LINE_TO` | 手順1-4のID |
4. エディタで関数 `testPush` を選んで実行する。初回は権限の承認を求められるので許可する。LINEに「テスト通知です」が届けばOK。
5. `testFind` 内の日付を、シートでCVが入っている日に書き換えて実行し、実行ログに通知文（例：`[本日はCVの投稿予定日です ころさん_CV3]`）が出ることを確認する。LINEには送られません。
6. 関数 `setupTrigger` を **1回だけ** 実行する。以降、毎朝8〜9時の間に自動でチェックされます。

## 変更したいとき

`Code.gs` 冒頭の定数を変えます。

- 通知時刻：`NOTIFY_HOUR`（変更後は `setupTrigger` を再実行）
- 対象のスプレッドシート・表示名：`ACCOUNTS`
- 列の位置：`DATE_COL`（C列=3）、`PLAN_COL`（E列=5）

## 注意点

- Apps Scriptの時間主導トリガーは「8時台のどこか」で動き、分単位の指定はできません。
- 投稿日付が「03/16」のような文字列の場合は月日だけで判定します。シートが1年以上の日付を含むようになると、前年の同じ月日にも反応する可能性があります。
- シート名「腸活ダイエット」や列の並びを変えると通知されなくなります。
