# CV投稿日のLINE通知

既存の Apps Script「投稿締切LINE通知」に、CV投稿日の通知を追加したものです。`投稿締切LINE通知.gs` が追加後のコード全体です。

## 動き

毎朝9時台のトリガーで `checkDeadlines()` が動くと、締切チェックの前に `checkCvPostDays()` も動きます。

- かめさん・ころさんの「腸活ダイエット」シートで、E列（企画）に `CV` を含み、C列（投稿日付）が今日の行を探す
- 見つかれば、締切アラートとは別の1通として送る

```
本日はCVの投稿予定日です かめさん_CV21
本日はCVの投稿予定日です ころさん_CV9
```

- 「CVリール21」のような企画名も `CV21` と表示します。
- 送信先・トークン（`LINE_TOKEN`）・トリガーは既存のものをそのまま使います。

## 反映手順

1. [投稿締切LINE通知](https://script.google.com/d/1NNBuFpujgelaxqG90FRWwfrDofXWRiOWFUXs5kmllPCsZ_VFxk8fprIo/edit) を開く。
2. 「コード」ファイルの中身を全部消して、`投稿締切LINE通知.gs` の中身を貼り付け、保存する。
3. 関数 `testCvPostDays` を実行し、実行ログに `[ '本日はCVの投稿予定日です ころさん_CV3' ]` のような行が出ることを確認する（LINEには送られません）。日付は関数内の `new Date(2026, 7, 10)`（＝2026/8/10、月は0始まり）を書き換えて試せます。
4. トリガーの作り直しは不要です（`setupTrigger` は実行しなくてよい）。

## 注意点

- CV通知と締切アラートは別々の1通として届きます。CV通知の分だけ月間の送信数が増えます。
- `broadcast` 送信なので、この公式アカウントの友だち全員に届きます（既存の仕組みと同じ）。
- 投稿日付が「03/14」のような年なしの文字列の場合、今日に近い年として扱います。翌年まで同じシートに古い行が残っていると、1年前の同じ日付の行にも反応します。
